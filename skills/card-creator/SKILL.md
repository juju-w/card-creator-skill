# Card Creator

“Magikarp × ICOCA, simple, ICOCA at lower right” is enough. Use the host's image-generation or image-editing tool for the complete card, including logos. Never draw artwork with code or paste logos onto a generated background. If the tool is unavailable, explain the limitation; do not substitute a script or claim an image was created.

1. Read the short [card rules](references/card-rules.md). For a new card, generate directly when the subject and style are clear. For a targeted edit, use the current image and change only what was requested; preserve other characters, composition, text and brand choices. Ask for the original only if it is needed and absent from the conversation.
2. Follow explicit logo choices, including “no logo.” Otherwise choose one familiar mark suited to the card type, subject, region and style. Respect requested bank/network combinations or logo-heavy designs without a count cap. Preserve brands in the user's reference unless asked to replace them. Distinguish transit products from operators; geographic relevance alone is not enough.
3. Prefer user attachments. If a mark needs a reference, find its name or alias in the [picture index](references/logo-reference-index.md) and open only the matching picture(s). Use available local pictures; if remote pictures cannot be reached, use a user reference or confident model knowledge. Search only when requested or identification is genuinely uncertain; ask for a reference if uncertainty remains. Do not scan the library, repeatedly retry downloads or read source histories.
4. Match logos to the artwork: foil, monochrome and line art are welcome. Use familiar card-face variants (usually compact UnionPay), not compact versions of every brand. Balance size and spacing visually, without fixed logo boxes.
5. Inspect the result for recognizable subjects and marks, obvious hand errors, unintended borders and transparency. For a clear mistake, make one targeted correction, then disclose any remaining issue instead of looping. Return the image with only useful brief notes, not a process report.

Wallet screenshots reference only the card, not the surrounding UI. Allow text intrinsic to the chosen marks; otherwise omit unrequested text, numbers, chips, QR codes and contactless/NFC indicators. Label third-party marks as non-official artistic interpretations, never authorization, endorsement or functioning cards. Do not publish private references without permission.
