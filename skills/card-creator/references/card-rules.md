# Card rules

- Default to a flat, edge-to-edge landscape image, about **1.586:1** (standard card proportions). Follow a different ratio if requested.
- Return the image generator's actual output. Do not promise exact pixels, print DPI or bleed files that were not produced. Printing preparation is a separate, explicitly requested task.
- Keep important details comfortably inside the picture; deliberate edge-to-edge illustration is fine. Balance spacing visually, without fixed safe-area boxes or logo-size limits.
- Unless requested, omit rounded-corner masks, frames, shadows, devices and wallet UI. Do not crop a finished composition merely to force the default ratio.
