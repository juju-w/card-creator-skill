# 参考卡面风格化改造

用户提供已有卡面、产品照片或手机钱包截图，并希望据此生成新设计时使用本模式。默认产出明显
不同的新构图，不做像素级复刻。

## 先分离卡面与截图界面

分析前先识别卡片矩形。忽略钱包余额、币种、手机靠近读卡器提示、应用界面、样机圆角、投影、
反光，以及卡片以外的社交平台水印。卡片存在透视时只能用于风格分析，不复制其几何变形。

## 提取设计语法

写 Prompt 前先用六项概括参考图：

1. **配色关系**：主背景、强调色、对比度，以及品牌色是否延伸到服装、线稿或建筑。
2. **构图区**：大留白、插画区、底部色带和 Logo 角位。
3. **线条与形状**：单线、轮廓角色、雕刻线稿、平涂色块、水彩或其他可见体系。
4. **纹样密度**：单个角色、重复纹样、叙事场景或建筑中心构图。
5. **气质与材质**：可爱、高级、市政、传统、冬日、纸张、金属等。
6. **标志模式**：默认使用 manifest 中 `ready` 的准确贴纸；只有用户明确要求时，才把可追溯
   标志作为 ImageGen 参考，生成标注为非官方的风格化诠释。

迁移这些关系，而不是复制原画。例如让角色的一件衣服吸收交通品牌色，把传统纹样转译为新的
线稿，或继承“大面积安静留白 + 一个小型叙事场景”的比例关系。

## 不得继承的内容

- 卡号、掩码数字、余额、币种、姓名、芯片、二维码、条形码或功能受理声明；
- 未获批准的银行、博物馆、交通、支付或非接触标志；用户明确选择非官方风格化模式时除外；
- 从参考图直接复制的专有插画；
- 钱包 UI、设备提示、样机阴影、圆角遮罩或截图水印。

布局依赖某个未就绪标志时，精确模式只预留位置并报告缺失。用户明确选择风格化模式时，保留
参考来源与最终 Prompt，把结果标注为非官方，并且绝不提升为 `ready`。只有用户明确要求研究
素材时，才按[贴纸研究与卡面提取](sticker-research.md)处理。

## 网页端直接复制模板

```text
请遵循 https://github.com/juju-w/card-creator-skill 的卡面规则，并参考我在当前对话上传的图片（参考图如上）。参考图可能是手机钱包截图：请只分析卡面区域，忽略余额、币种、读卡提示、应用界面、样机圆角、阴影和水印。

不要照抄原卡。请先提取它的设计语法，包括配色关系、留白、构图区、线条粗细、纹样密度和整体气质，再用这些关系创作一个明显不同的 [目标主题] 风格化版本。输出横向平面卡面，宽高比 1.58577:1，目标裁切尺寸 1011 × 638 px、300 DPI，所有重要内容位于中央安全区。

不要复制卡号、掩码数字、姓名、芯片、余额、二维码、条形码、发卡方文字或不可用 Logo。为 [所需贴纸] 预留干净位置；如果我上传了已验证的透明贴纸，请把它作为不可变图层使用，否则保持空位。只输出卡面画稿，不要手、设备、样机、透视、圆角遮罩、边框或阴影。请生成一张完整预览，并附上最终使用的 Prompt。
```
