# 卡面生成器

直接说“鲤鱼王 × ICOCA，简洁，右下角 ICOCA”，或上传图片后说“只把标志改成深蓝，其余保持”。

需要当前客户端提供图片生成或编辑能力。本分发包的图片索引使用远程链接；完整本地图片可从 GitHub 主包获取。下面的执行规则与 GitHub、网页入口共用同一份源文件，无需用户阅读英文规则才能使用。
